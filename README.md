# Проект ProjectDjango

## Описание:
Проект представляет приложение с html страницами. 
Страница "Контакты" подразумевает отправку post-запроса с личными данными.





## Установка:

1. Клонируйте репозиторий:

```
git@github.com:Daria149/ProjectDjango.git
```


2. Установите зависимости:

```
через poetry init
```

## Использование:
Проект содержит информацию о товарах для продажи на главной странице и страницу Блога со статьями.
Для оптравки запроса для обратной связи внесите свои контактные данные на странице.
Для просмотра детальной информации о товарах, их редактирования необходима регистрация.
Для работы с базой данных измените название файла .env.sample на .env и внесите в файл личные данные.
Для реализации функциоанала отправки писем на электронные почты при регистрации также необходимо изменить название файла .env.sample на .env 
  и внести почту, с которой будут отправляться письма.
