# Проект ProjectDjango

## Описание:
Проект представляет приложение с html страницами. 
Страница "Контакты" подразумевает отправку post-запроса с личными данными.






## Установка:

1. Клонируйте репозиторий:

```
git@github.com:Daria149/ProjectDjango.git
```

2. Установите зависимости:

```
pip install -r requirements.txt или через poetry init
```

## Использование:
Можете просмотреть главную страницу с товарами для продажи. 
Для оптравки запроса для обратной связи внесите свои контактные данные.
